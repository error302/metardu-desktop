## 2026-09-11 - [XSS Prevention in CrossSectionView]
**Vulnerability:** The `CrossSectionView.tsx` component was directly rendering an SVG string generated from a function into the DOM using `dangerouslySetInnerHTML`. If any part of the `CrossSectionData` (e.g., the `feature` string) came from user input and was maliciously crafted, it could execute arbitrary JavaScript within the application context.
**Learning:** Even when generating SVGs programmatically, any dynamic strings (like labels or titles) included in the SVG markup can introduce XSS risks if they are not sanitized before being rendered with `dangerouslySetInnerHTML`. This is especially true for Electron apps where the renderer could potentially access sensitive APIs.
**Prevention:** Always sanitize raw HTML/SVG strings using `DOMPurify` before passing them to `dangerouslySetInnerHTML`. When dealing with SVGs, configure DOMPurify with `{ USE_PROFILES: { svg: true } }` to ensure valid SVG elements and attributes are preserved while stripping malicious content.
