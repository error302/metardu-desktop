## 2024-05-24 - [XSS via raw SVG in dangerouslySetInnerHTML]
**Vulnerability:** A Cross-Site Scripting (XSS) vulnerability was found in React components rendering dynamically generated SVG strings using `dangerouslySetInnerHTML`. The raw SVG strings, potentially containing unsanitized attributes or embedded scripts, were directly injected into the DOM.
**Learning:** Using `dangerouslySetInnerHTML` even for seemingly safe content like dynamically generated SVGs carries a high risk if any part of the generation involves user input or unvalidated data. React's built-in XSS protection does not apply when using `dangerouslySetInnerHTML`.
**Prevention:** Always sanitize HTML/SVG strings with `DOMPurify` before passing them to `dangerouslySetInnerHTML`. When sanitizing SVG strings, ensure the `{ USE_PROFILES: { svg: true } }` option is passed to DOMPurify so that necessary SVG elements and attributes are retained while dangerous content is stripped. Include an explicit in-code comment explaining the security concern when `dangerouslySetInnerHTML` is used.
