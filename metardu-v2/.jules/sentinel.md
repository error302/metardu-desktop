## 2025-02-12 - [HIGH] XSS Vulnerability in dynamically generated SVG content
**Vulnerability:** The application was dynamically generating raw SVG strings in `CrossSectionView.tsx` and passing them directly to React's `dangerouslySetInnerHTML` without any sanitization. This allowed for potential Cross-Site Scripting (XSS) attacks if user-supplied data, or external data, is processed by the SVG generator and injected un-escaped into the React component tree.
**Learning:** React requires explicit and careful handling of dynamically generated raw HTML/SVG content. Calling `dangerouslySetInnerHTML` with raw input bypasses standard React protections.
**Prevention:** Before rendering raw SVG (or HTML) in `dangerouslySetInnerHTML`, always sanitize the content using `DOMPurify` or an equivalent library. When dealing with SVGs in DOMPurify, be sure to use the `{ USE_PROFILES: { svg: true } }` option so legitimate elements are not inappropriately stripped. Always add explanatory in-code comments detailing why security sanitization steps are taken for future maintainers.
