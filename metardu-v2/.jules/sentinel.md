## 2026-10-21 - DOMPurify usage for SVG dangerouslySetInnerHTML\n**Vulnerability:** XSS vulnerability through unchecked SVG HTML source\n**Learning:** When using `dangerouslySetInnerHTML` to render React SVG components from a string, it is critical to sanitize the source data, even if it comes from internal generators, because if any underlying data string contains unescaped user inputs, XSS attacks become possible.\n**Prevention:** Use DOMPurify.sanitize(rawSvg, { USE_PROFILES: { svg: true } }) to safely sanitize SVG strings before passing to dangerouslySetInnerHTML. The `USE_PROFILES: { svg: true }` setting is necessary to ensure the core SVG attributes and elements are not stripped out by the sanitizer.
