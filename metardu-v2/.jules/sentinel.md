## 2026-08-21 - [SVG XSS in dangerouslySetInnerHTML]
**Vulnerability:** A Cross-Site Scripting (XSS) vulnerability was found in `CrossSectionView.tsx` where an SVG was generated manually as a string and rendered using React's `dangerouslySetInnerHTML`. The string generation interpolated unescaped user-controlled values (`p.feature`), allowing arbitrary HTML/script injection via the feature labels.
**Learning:** SVG content constructed through string concatenation or template literals and rendered via `dangerouslySetInnerHTML` bypasses React's built-in XSS protections. All user-controlled text injected into such strings must be manually escaped (e.g. for HTML entities) or the whole output sanitized before rendering.
**Prevention:** Avoid string-building SVGs for rendering with `dangerouslySetInnerHTML`. Instead, build SVG components using React JSX elements where React naturally escapes strings. If `dangerouslySetInnerHTML` is unavoidable, explicitly escape all dynamic inputs (e.g., using an `escapeHtml` utility or a library like DOMPurify) before inserting them into the raw markup string.
